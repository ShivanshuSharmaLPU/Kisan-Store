# 🌾 KisanMitra Store

KisanMitra Store is a modern agriculture e-commerce and farmer assistance platform built using React, TypeScript, Vite, Tailwind CSS, and shadcn/ui. The platform helps farmers explore agricultural products while also integrating AI-based crop recommendation support.

---

# 🚀 Features

## 🛒 E-Commerce Features

* Browse agricultural products
* Product categories
* Shopping cart system
* Order management
* User authentication
* Profile management
* Admin dashboard
* Product analytics
* Revenue visualization
* Mobile responsive UI

## 🤖 KisanMitra AI Integration

* AI Crop Recommendation access
* Smart farming support
* Separate AI module integration
* Quick navigation from store to AI platform

## 👨‍💼 Admin Features

* Add/Delete products
* View registered users
* View all orders
* Analytics dashboard
* Sales charts
* Revenue distribution
* Low stock monitoring

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone <your-repository-url>
```

## 2. Open Project Folder

```bash
cd KisanMitraStore
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start Development Server

```bash
npm run dev
```
